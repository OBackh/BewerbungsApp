Bemo ist eine Web-App, die Bewerber:innen hilft, den Überblick über ihre Bewerbungen zu behalten. Nutzer:innen können Bewerbungen hinzufügen, bearbeiten, löschen und den Status ihrer Bewerbungen verfolgen.

🏢 Features
	•	Bewerbungen mit Firma, Position, Status und Notizen hinzufügen
	•	Bearbeiten und Löschen bestehender Bewerbungen
	•	Übersicht aller Bewerbungen nach Status
	•	Vollständige CRUD-Operationen

⚙️ Technologien
	•	Java / Spring Boot (Backend)
	•	JavaScript / React (Frontend)
	•	MongoDB (Datenbank)
	•	REST APIs

🎯 Ziel
Ein Praxisprojekt zur Festigung von Fullstack-Kenntnissen in Java und JavaScript/React, zur Anwendung von CRUD-Operationen und zur Entwicklung einer strukturierten, modernen Web-Anwendung.

Bemo

Bemo is a web application that helps job applicants keep track of their applications. Users can add, edit, delete applications, and monitor the status of each application.

🏢 Features
	•	Add applications with company, position, status, and notes
	•	Edit and delete existing applications
	•	Overview of all applications by status
	•	Full CRUD operations

⚙️ Technologies
	•	Java / Spring Boot (Backend)
	•	JavaScript / React (Frontend)
	•	MongoDB (Database)
	•	REST APIs

🎯 Purpose
A practice project to reinforce fullstack skills in Java and JavaScript/React, apply CRUD operations, and build a structured, modern web application.
